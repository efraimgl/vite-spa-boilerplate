# Vite SPA Boilerplate

A minimal boilerplate for building single-page applications with Vite.

## Features

- ⚡️ Lightning fast development with Vite
- 📦 Optimized build process
- 🔥 Hot Module Replacement (HMR)
- 🎨 Vanilla JavaScript - easy to extend

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

```
vite-spa-boilerplate/
├── public/          # Static assets
├── src/             # Source files
│   ├── main.js      # Application entry point
│   └── style.css    # Styles
├── index.html       # HTML template
└── vite.config.js   # Vite configuration
```

## Customization

This is a minimal boilerplate. You can easily extend it with:

- Your favorite framework (React, Vue, Svelte, etc.)
- CSS preprocessors (Sass, Less, etc.)
- TypeScript
- State management libraries
- Routing solutions
